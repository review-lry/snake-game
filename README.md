# 🐍 贪吃蛇游戏

一个使用 HTML5 Canvas 制作的经典贪吃蛇游戏，支持桌面和移动设备。

## ✨ 特性

- 🎮 响应式设计，支持桌面和移动端
- 📱 移动端虚拟按键控制
- 💾 本地存储最高分记录
- 🎨 渐变色彩和动画效果
- ⏸️ 暂停/继续功能
- 🔄 游戏结束后快速重开

## 🕹️ 操作方式

### 桌面端
- **方向键** 或 **WASD** 控制蛇的移动
- 点击"开始游戏"按钮开始
- 点击"暂停"按钮暂停游戏

### 移动端
- 使用屏幕上的虚拟方向键控制

## 🚀 本地运行

1. 打开 `index.html` 文件即可在浏览器中运行

## 🎯 游戏规则

- 控制蛇吃到红色的食物
- 每吃到一个食物，蛇会变长，得分增加 10 分
- 撞到墙壁或自己的身体，游戏结束
- 争取创造最高分纪录！

## 📊 技术栈

- HTML5 Canvas
- 原生 JavaScript
- CSS3 渐变和动画
- LocalStorage 本地存储
